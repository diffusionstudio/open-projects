# take-on-me

A Claude skill that turns a short story idea into a hand-drawn pencil-animation film inspired by a-ha's "Take On Me": a colour world, a boiling graphite sketch world, and a character who crosses between them. 100 % code, rendered in [Diffusion Studio](https://github.com/diffusionstudio/editor). A finished film lives in [example/fish-heist](example/fish-heist).

## Install

Visit [diffusion.studio](https://www.diffusion.studio/), download the app, and install its MCP server. Then paste into Claude Code:

```
Install the take-on-me skill: clone https://github.com/diffusionstudio/open-projects and copy its
take-on-me folder to ~/.claude/skills/take-on-me.
```

## Make a video

```
Use the take-on-me skill to make a 20 second video: a goldfish spots a sketched ocean on the
newspaper under its bowl, leaps in, and has to outswim a pencil shark to get home.
```
