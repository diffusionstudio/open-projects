# Open Projects

A collection of projects generated with [Diffusion Studio](https://github.com/diffusionstudio/editor) —
video compositions written as code, mounted and rendered through the `dapi` CLI.

Each folder is a self-contained project with its own instructions.

| Project | What it is |
|---|---|
| [launch-video](launch-video) | The Diffusion Studio launch video, written as a Solid JSX composition. |
| [raise-announcement](raise-announcement) | A funding-announcement motion graphic, with the design brief it was built from. |
| [take-on-me](take-on-me) | A Claude skill that turns a story idea into an a-ha "Take On Me" style pencil animation, with an example film. |

## Getting started

Install Diffusion Studio on macOS:

```sh
brew install --cask diffusionstudio/tap/editor
```

Then follow the README or design brief inside the project you want to run.
